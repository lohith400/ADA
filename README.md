## 🔍 Detailed Experiment Breakdown

### Experiment 1: Search Algorithms
* **Objective:** Implement search algorithms using Brute Force and Divide and Conquer techniques.
* **Analysis:** Calculate execution time across varying input sizes ($n$) and generate a performance plot (Time vs $n$).

### Experiment 2: Sorting Programs
* **Objective:** Develop sorting implementations and benchmark execution times for different values of $n$ ($n$ = number of elements).
* **Technique Breakdown:** 
  - *Brute Force* (e.g., Bubble Sort / Selection Sort)
  - *Divide and Conquer* (e.g., Merge Sort / Quick Sort)
  - *Decrease and Conquer* (e.g., Insertion Sort / Heap Sort)
  - *Input-Enhancement* (e.g., Counting Sort / Distribution Sort)

### Experiment 3: 0/1 Knapsack Problem
* **Objective:** Solve the 0/1 Knapsack optimization problem using multiple algorithmic paradigms to compare efficiency and correctness.

### Experiment 4: Single Source Shortest Paths
* **Objective:** Implement algorithms to find the shortest path from a single source node to all other nodes in a weighted graph.
* **Technique Breakdown:** Greedy (e.g., Dijkstra's algorithm) vs. Dynamic Programming (e.g., Bellman-Ford algorithm).

### Experiment 5: Warshall’s and Floyd’s Algorithms
* **Objective:** Implement graph algorithms using dynamic programming to find transitive closure (Warshall's) and all-pairs shortest paths (Floyd's).

### Experiment 6: String Matching Algorithms
* **Objective:** Implement text search and pattern matching algorithms using straightforward matching and pre-processing input-enhancement techniques (e.g., Horspool / Boyer-Moore).
